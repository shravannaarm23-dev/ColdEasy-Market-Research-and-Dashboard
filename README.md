# ColdEasy Competitive Analysis Dashboard

## Overview
This Power BI project compares ColdEasy with Sabjee Cooler using pricing, capacity, technology, and customer segmentation analysis.

## Tools Used
- Power BI
- Microsoft Excel

## Key Insights
- Price comparison between competitors
- Capacity benchmarking
- Technology comparison
- Customer segmentation and priority scoring
